# saya-lab

deliberately failing test. The live proof is a Slack thread in saya's lab channel:
"fix the failing test and open a draft PR", then a draft pull request from saya's
GitHub App with the thread link in its body, and CI's result posted back in the thread.

Nothing here is production code.
